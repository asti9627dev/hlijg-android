# مشروع مادتي لأندرويد

- اسم التطبيق: مادتي
- اسم الحزمة: `net.madty.app`
- الموقع: `https://www.madty.net/`
- لون شريط النظام: `#0D767C`
- الواجهة تعرض الموقع عبر WebView.

## بناء APK عبر GitHub Actions

1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد.
2. افتح تبويب **Actions**.
3. اختر **Build Madty APK** ثم اضغط **Run workflow**.
4. بعد نجاح التشغيل، افتح نتيجة التشغيل وابحث عن **Artifacts**.
5. نزّل `madty-debug-apk` وفك ضغطه لتحصل على `app-debug.apk`.

## ملاحظات مهمة

- هذا مشروع Android أولي جديد يعرض الموقع داخل التطبيق، وليس إعادة بناء للتطبيق القديم المستخرج من APKS.
- ملف APK الناتج سيكون نسخة debug موقعة للتجربة، وليس إصدارًا production جاهزًا للنشر في Google Play.
- يجب اختبار الموقع والتنزيلات وملفات PDF على جهاز فعلي قبل الاعتماد عليه.
- لا يتضمن المشروع شعارًا مخصصًا بعد؛ يمكن إضافة ملفات الشعار والأيقونات لاحقًا.
